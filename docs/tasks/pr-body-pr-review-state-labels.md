## 背景

PRレビューで指摘を投稿した時に、PR一覧から「修正待ち」であることが分かるようにしたい。

既存の skill では `review:まーじOK` の付与・除去だけを扱っていたため、指摘ありレビュー時の `PRレビュー修正待ち` が明確な手順になっていなかった。

## 概要

PRレビュー状態ラベルを `PRレビュー/再レビュー待ち`、`PRレビュー修正待ち`、`review:まーじOK` の 3 状態として排他的に扱う手順へ整理した。

## 変更内容

- `github-pr-review` に、指摘ありレビュー時は `PRレビュー修正待ち` を付ける手順を追加
- OK 専用の `review-ok-label.md` を、3 状態を扱う `review-state-labels.md` に置き換え
- 再チェック結果に応じて `review:まーじOK` / `PRレビュー修正待ち` を切り替える手順を追加
- PR 作成後は `PRレビュー/再レビュー待ち` にする手順を追加
- FB 対応完了後は `PRレビュー/再レビュー待ち` に戻す手順を追加
- セルフレビューでは PRレビュー状態ラベルを更新しない旨を明記
- `AGENTS.md` と skill README / LEVELUP の説明を更新
