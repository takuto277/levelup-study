# Privacy Policy

LevelUp Study respects user privacy.

## Data Collected
- Study time, genre, session history
- Gacha/character/weapon/party data
- Anonymous device identifier

## Data NOT Collected
- Location, contacts, photos
- Personal identifying info (except auth)

## Usage
- Study record display and analysis
- Game features (battle, rewards, gacha)
- Service improvement statistics

## Data Deletion
Account deletion removes all data.
